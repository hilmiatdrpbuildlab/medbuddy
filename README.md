# VitalsBrief (codename) — Investor Demo

Demo mobile app (iOS + Android) untuk investor pitch: import laporan lab → Lab Organizer & grafik tren → data wearable → GP Brief 1 halaman.

> Nama sementara. "MedBuddy" tidak dipakai karena kemungkinan bentrok merek.

## Dokumen

- [Rencana pengembangan demo](docs/DEMO_PLAN.md)

## Stack (rencana)

React Native + Expo (TypeScript), Expo Router, NativeWind, i18next (EN / NL / FR), expo-print. Halaman QR GP Brief dan versi web cadangan di-deploy ke Cloudflare Pages.
